# Programming vs Programming Language

## What is Programming?

Programming is a set of instructions in correct order to complete a task/solve a problem.

## What is a Programming Language?

Programming Language is just a language that is used to express the set of instructions for the computer so it can understand.

## What is Python?

Python is a programming language.

## What is Syntax?

Syntax is a set of rules that we need to follow when we are programming.

## Programming and Python

Programming is the set of instructions in correct order to perform a task or solve a problem. Python is a just a programming language to express the set of instructions so that the computer can understand.

## What remained the Same?

In Pseudocode and Python the logic is same. We have input, process and output.

## What Changed?

Pseudocode is writing the logic in plain English without following any syntax. Whereas in Python, we need to follow the syntax.

## My Final Understanding

Programming helps me: to write the set of instructions needed to solve a problem or perform a task.

Python helps me: to write the instructions in a way that the computer can understand.

Syntax tells me: to write the code in the specified rules.
