# Why Programming Languages Exist

## Why Does a Computer Need Instructions?

A Computer can do any task, but before doing any task, It needs a set of clear instructions to do it. Because it does not what we need, so we need to give instructions for it follow.

## Why Can We Not Build Applications Using Normal Human Language?

A Computer works on electrical states that is 0 and 1. So for it to understand human language is impossible, it can only understand machine level language.

## What Problem Do Programming Languages Solve?

Programming Languages are the bridge between humans and computers.

## Why Is Machine Language Difficult for Human?

Machine Language is in Binary format, it is very difficult to write and understand for humans.

## How Does Python Help?

Python is a programming language, which is like a bridge between humans and computers. Python is also a High Level Language, which is very easy to understand for humans.
